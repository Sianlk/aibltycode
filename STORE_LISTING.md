## Build Instructions

### Android (.aab for Play Store)
```bash
git pull
npm install
npm run build
npx cap sync android
# Open in Android Studio:
npx cap open android
# Build > Generate Signed Bundle / APK > Android App Bundle
```

### iOS (.ipa for App Store)
```bash
git pull
npm install
npm run build
npx cap sync ios
# Open in Xcode:
npx cap open ios
# Product > Archive > Distribute App
```
